## 数据库升级

SQLite `PRAGMA user_version` 从 3 增量升级到 4，新增 `project_plan_state` 和 `plan_runs`。迁移仅新增表和索引，不删除或覆盖账号、项目、需求、任务、依赖、事件、工时、计划日期及成员容量。程序遇到高于 schema 4 的数据库会拒绝启动。

已在当前正式库副本执行 v3 → v4 并重复迁移：升级前后用户、项目、需求、任务、事件、依赖和成员容量记录数保持一致，第二次迁移不重复创建或修改业务记录；正式数据库本身未在验证中写入。

## 人工复演

1. 给成员维护周容量和可用时段，给同一需求创建一个锁定任务和一个待办未锁定后继任务。
2. 修改需求并打开“排期影响”，核对可重排与保留任务清单，再由管理员填写确认原因。
3. 查看排期结果，确认锁定任务日期未变，后继任务按依赖和容量更新，状态与验收结论未变化。
4. 在甘特图核对任务 ID、日期、负责人、工时与依赖，点击任务条进入同一任务详情。
5. 在成员任务图核对工作量、容量、负荷率、未分配任务和已移除成员历史归属。
6. 保持成员任务图打开，在另一会话修改看板负责人或状态，确认 5 秒内刷新到相同任务版本；断网时确认提示未同步，恢复后重读。

自动化通过不等同于团队人工签认。非作者复验、产品负责人接受及课程要求的签字仍需团队完成。
